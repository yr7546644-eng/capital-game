# CAPITAL 商会バトル

5年(60か月)で町いちばんの商会を目指す、スマホ向けの経営バトルゲーム。
ブラウザで開くだけで遊べる(ホーム画面に追加するとアプリのように全画面で動く)。

- 町の空き地に店(パン屋・薬屋・鍛冶屋・仕立て屋)を開く
- 値段・店員・広告を決め、同じ地区・同じ業種のライバルとお客を取り合う
- 資源の市場はみんなで共有。買い占めると値上がりする
- 毎月3枚配られるカードから1枚を使う
- 来月の予報を見て先回りする
- ライバルと「毎月◯個を◯Gで」の契約を結ぶ(翌月払い・売掛金の前倒し・つなぎ融資で資金繰り)
- 町の依頼・ギルドの投票・年末の税・店の買い取り
- ライバルAIは4段階(ふつう/つよい/鬼/魔王)。鬼と魔王は毎月の手を一つずつ未来まで試算して選ぶ
- 友だちとオンライン対戦(部屋の番号を送るだけ。空いた席はAI)
- BGM 7曲と効果音はその場で合成(音声ファイルなし)

## 動かし方(手元)

```
python3 -m http.server 8000
```

で `http://localhost:8000/` を開く。ビルドは不要。

## ファイル

- `js/engine.js` … ゲームの計算(画面に依存しない。同じ種と同じ決断なら必ず同じ結果)
- `js/board.js` … 3D の町(three.js)
- `js/main.js` … 画面と操作
- `js/sfx.js` … BGMと効果音(Web Audio で合成)
- `js/aiworker.js` … ライバルAIの思考(別スレッド)
- `js/net.js` … オンライン対戦(Supabase Realtime。ホストが計算して結果を配る)
- `assets/` … 3D モデル(CC0)

素材のクレジットは [CREDITS.md](CREDITS.md)。

## ルーンはじき(新作) — `rune/`

駄菓子屋の十円ゲームをファンタジーにした、はじきゲーム。https://yr7546644-eng.github.io/capital-game/rune/

- 画面を下へ引いて離すと、ルーンコインが飛ぶ。奥の門に入ればボスにダメージ
- 左右の壁やクリスタルで跳ねるたびにコンボ+1(ダメージが上がる)。壁の金の板は「はじく」で打ち返せる
- 奈落の穴に落ちるとボスが回復。魔物が自分の城へ歩いてくるので、コインで倒して守る
- ボスは穴を開ける・横風・地揺れ・結界・召喚・重力でじゃまをする。こちらは光の橋・炎のコイン・分身・時の砂・守りの壁
- 3ステージ(スライム王の森・黒騎士の墓所・魔王城)。3Dは three.js、人形と建物は KayKit(CC0)、音はすべてその場で合成

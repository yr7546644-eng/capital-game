# CAPITAL 商会バトル

5年(60か月)で町いちばんの商会を目指す、スマホ向けの経営バトルゲーム。
ブラウザで開くだけで遊べる(ホーム画面に追加するとアプリのように全画面で動く)。

- 町の空き地に店(パン屋・薬屋・鍛冶屋・仕立て屋)を開く
- 値段・店員・広告を決め、同じ地区・同じ業種のライバルとお客を取り合う
- 資源の市場はみんなで共有。買い占めると値上がりする
- 毎月3枚配られるカードから1枚を使う
- 来月の予報を見て先回りする
- ライバルと「毎月◯個を◯Gで」の契約を結ぶ(翌月払い・売掛金の前倒し・つなぎ融資で資金繰り)
- 町の依頼・ギルドの投票・年末の税・店の買い取り
- ライバルAIは4段階(ふつう/つよい/鬼/魔王)。鬼と魔王は毎月の手を一つずつ未来まで試算して選ぶ
- 友だちとオンライン対戦(部屋の番号を送るだけ。空いた席はAI)
- BGM 7曲と効果音はその場で合成(音声ファイルなし)

## 動かし方(手元)

```
python3 -m http.server 8000
```

で `http://localhost:8000/` を開く。ビルドは不要。

## ファイル

- `js/engine.js` … ゲームの計算(画面に依存しない。同じ種と同じ決断なら必ず同じ結果)
- `js/board.js` … 3D の町(three.js)
- `js/main.js` … 画面と操作
- `js/sfx.js` … BGMと効果音(Web Audio で合成)
- `js/aiworker.js` … ライバルAIの思考(別スレッド)
- `js/net.js` … オンライン対戦(Supabase Realtime。ホストが計算して結果を配る)
- `assets/` … 3D モデル(CC0)

素材のクレジットは [CREDITS.md](CREDITS.md)。

## ルーンはじき(新作) — `rune/`

駄菓子屋の十円ゲーム(新幹線ゲーム)をファンタジーにしたもの。https://yr7546644-eng.github.io/capital-game/rune/

- 「コインを入れる」で左上からルーンコインが入り、ジグザグのレールを転がり落ちる
- レールの穴に落ちると「はずれ」(ボスが回復)。その段のレバー(左右の枠、または画面のその高さ)を押すと、コインがはね上がって穴を飛びこえる
- 一番下の魔法砲に届くと「当たり」。光の柱がボスに命中し、飛びこえた数・倒した魔物の数でコンボダメージが上がる
- 魔物は同じ道を城へ下りてくる。コインで倒すとマナがたまり、スキル(光の橋・炎のコイン・分身・時の砂・守りの壁)が使える
- ボスは穴を開ける・横風・地揺れ・結界・召喚・重力でじゃまをする。3ステージ(スライム王の森・黒騎士の墓所・魔王城)
- 3Dは three.js、人形と建物は KayKit(CC0)、音はすべてその場で合成

## キャピタル商会戦争(新作) — `war/`

カードで投資して、ライバル商会と1対1で戦うゲーム。時間制限なし。https://yr7546644-eng.github.io/capital-game/war/

- 毎月ニュースが3つ出る(確実 約88%・有力 約72%・うわさ 約55%)。「鉄が下がるかも」のように予想が書いてある
- 手札5枚から投資カードを3枚まで選ぶ(「▲上がる」「▼下がる」、強さ×1〜×3、どちらでも儲かる「両張り」)。いらないカードは「捨てて引く」で2回まで引き直せる
- 決算: 1枚ずつめくってチャートが動き、儲けが出る。役で倍率アップ
  - 的中 ×1.5(ニュースどおりに賭けて当たった)/一点集中 ×1.5(同じ資源に2枚)/分散 ×1.3(3つとも別の資源)/パーフェクト ×2(3枚とも儲け)
- ライバルとの儲けの差がダメージ。相手の信用ゲージを0にしたら勝ち、自分のが0になったら負け
- 相手は3人: 逆張りのロウ → ニュースを1つ隠すミーナ → 大相場(値動き1.6倍)のボス ガルド
- 月の合間のお店: 顧問(ずっと効くボーナス。最大4人)、強いカードを買う、弱いカードを捨てる
- 資源5つ(小麦・鉄・薬草・布・星銀)と会社3つ(王都銀行・海運商会・魔導工房)。魔導工房は星銀につられて動く
